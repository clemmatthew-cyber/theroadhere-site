# The Road Here landing page

A standalone static holding page for The Road Here, described as an app in development. It includes no forms, analytics, scripts, app interfaces, recordings, or invitations. Open `index.html` locally or serve the folder with `python -m http.server 8080`.

The site is configured for GitHub Pages from the `main` branch at `theroadhere.com`. DNS and HTTPS provisioning may take time; check certificate trust and HTTP-to-HTTPS redirects before announcing availability. Keep the GitHub Pages domain-ownership TXT record in DNS. The original DNS baseline is maintained in the private project handoff. No final product publisher or ownership claims are made here.
